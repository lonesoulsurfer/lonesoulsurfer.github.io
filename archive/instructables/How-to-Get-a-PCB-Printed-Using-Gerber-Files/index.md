## Step 1: Gerber Files

![Step 1: Gerber Files image 1](images/step01_01.jpg)

![Step 1: Gerber Files image 2](images/step01_02.jpg)

Gerber Files - These are the zipped files that contain information on each of the physical board layers of your PCB. They are used by the manufacture to print and make the board. It's not really necessary to understand all the different layers if you are just getting the board printed. If you want to design your own then you'll need to have an understanding of what each layer does.

The Gerber files are typically generated by the PCB design software that you’re using. In my case I use Eagle to design my PCB's.

Once the PCB has been designed in Eagle, you can then generate the gerber files which come as a zipped file. If you open the gerber file up you'll see a number of different files, each presenting a different part or layer that goes into making up the PCB. I have included an image of the files inside the gerber file so you can take a look at them.

Don't worry, you don't have to design the PCB as it has already been done. All you need to do is to send the files to a PCB manufacturer to print for you.

For this Instructable, I have included a link to my Google Drive where I have stored a Schematic, Board and Gerber file. I'll be using this gerber file as an example.

[Link to Google Drive File](https://drive.google.com/drive/folders/1L0cG3s8eofmWnCaaOoxGSxFMp1p22EOy?usp=sharing)

STEPS:

1. Open the Google Drive file

2. Right click on the Gerber file and Download and Save the Gerber file to your computer


## Step 2: Creating an Account With a PCB Manufacturer

![Step 2: Creating an Account With a PCB Manufacturer image 1](images/step02_01.jpg)

![Step 2: Creating an Account With a PCB Manufacturer image 2](images/step02_02.jpg)

If you type in PBC manufacturer in Google, you'll come up with a whole bunch of different companies that can do it for you. for this example, I will be using JLCPCB (not affiliated) but there are plenty of others like [PCB Way](https://www.pcbway.com/), [OSH Park](https://oshpark.com/), [Next PCB](https://www.nextpcb.com/?utm_campaign=pcb-au&adgroupid=87593250155&utm_source=google&utm_medium=cpc&utm_term=e&keyword=pcb%20manufacturer&gclid=Cj0KCQjw6NmHBhD2ARIsAI3hrM0D1ifqH1Mir42gMWBU232j1Z_dLVSe2wNnnxp15H6TH3GSYTn5-LkaAr5MEALw_wcB) etc

STEPS:

1. Go to [JLCPCB](http://jlcpcb.com) website

2. Create an account. You can just use a Google account as a sign in which I find is the easiest way


## Step 3: Adding the Gerber File

![Step 3: Adding the Gerber File image 1](images/step03_01.jpg)

![Step 3: Adding the Gerber File image 2](images/step03_02.jpg)

![Step 3: Adding the Gerber File image 3](images/step03_03.jpg)

![Step 3: Adding the Gerber File image 4](images/step03_04.jpg)

![Step 3: Adding the Gerber File image 5](images/step03_05.jpg)

STEPS:

1. Once you are logged in, hit the 'Quote Now' button on the front page

2. Next, hit the 'Add Gerber File' button and add the saved gerber file

3. A status bar will appear showing the gerber file being loaded

4. Once it is fully loaded, you will see back and front images of the PCB

5. You can also change the colour of your board easily by choosing one of the available colours


## Step 4: Saving to Cart and Checkout

![Step 4: Saving to Cart and Checkout image 1](images/step04_01.jpg)

![Step 4: Saving to Cart and Checkout image 2](images/step04_02.jpg)

STEPS:

1. Once you are happy with the colour of the PCB, hit the 'Save to Cart' button

2. Next hit the 'Secure Checkout' button and add your shipping and payment details

3. That's it. Now just sit back and wait for your printed PBC boards to arrive.
