# lonesoulsurfer - Instructables Archive

Personal project index and offline archive for all my Instructables.

**Live site:** lonesoulsurfer.github.io

---

## Want to build your own?

This site was built using a tool I put together that automatically scrapes your Instructables profile, downloads every project as a full offline archive, and publishes it as a free website on GitHub Pages.

Check out the tool here:

**github.com/lonesoulsurfer/instructables-archive**

It includes a one-click setup script. Download the ZIP, double-click run.bat (Windows) or run.sh (Mac/Linux), answer three questions, and it handles everything else automatically.

## What this archive contains

- A searchable, filterable website listing all 257 of my Instructables
- A full offline copy of every project with text, images and PDFs
- Image zoom, clickable parts list links and PDF download buttons
- Hosted free on GitHub Pages
