# lonesoulsurfer.github.io

Personal project index and archive for all Instructables by lonesoulsurfer.

Live site: https://lonesoulsurfer.github.io

---

## What this repo contains

`index.html` -- the website. Reads from `projects.json` and renders a filterable, searchable grid of all projects. Hosted via GitHub Pages at no cost.

`projects.json` -- the single source of truth for all project data. Generated by the scraper. This is what the site reads.

`scraper/` -- two Python scripts:
- `scrape.py` -- scrapes your Instructables profile and regenerates `projects.json`
- `download_archive.py` -- downloads every Instructable as markdown + images for offline keeping

`archive/` -- local copies of every Instructable as markdown with all images downloaded. Your insurance policy if Instructables ever goes down.

---

## Setup

### 1. Create the repo on GitHub

```bash
# Create a repo named exactly: lonesoulsurfer.github.io
# Then clone it locally
git clone https://github.com/lonesoulsurfer/lonesoulsurfer.github.io
cd lonesoulsurfer.github.io
```

### 2. Add the files

Copy `index.html`, `projects.json`, and the `scraper/` folder into the repo.

### 3. Enable GitHub Pages

Go to the repo Settings > Pages > Source: Deploy from branch > Branch: main > Folder: / (root)

Your site will be live at `https://lonesoulsurfer.github.io` within a minute or two.

### 4. Set up Git LFS (for the archive images)

```bash
git lfs install
git lfs track "archive/**/*.jpg"
git lfs track "archive/**/*.jpeg"
git lfs track "archive/**/*.png"
git lfs track "archive/**/*.gif"
git lfs track "archive/**/*.webp"
git add .gitattributes
git commit -m "configure git lfs"
git push
```

### 5. Install scraper dependencies

```bash
pip install requests beautifulsoup4 markdownify
```

## Keeping it current

After publishing a new Instructable:

```bash
cd scraper
python3 scrape.py
cd ..
git add projects.json
git commit -m "add: <project title>"
git push
```

The site updates immediately once the push lands.

To keep the offline archive current at the same time:

```bash
cd scraper
python3 download_archive.py --new-only
cd ..
git add archive/
git commit -m "archive: <project title>"
git push
```

## Dependencies

- Python 3.8+
- `requests`, `beautifulsoup4`, `markdownify` (pip install)
